# 🛠️ LangGraph Code Fixer

An AI-powered Python debugging assistant built with **Streamlit** and **LangChain / LangGraph**. Powered by **Google Gemini**, it analyzes broken Python scripts, streams real-time fixes, and provides step-by-step breakdowns for syntax and runtime errors.

---

## 🚀 Features

* ⚡ **Real-Time Token Streaming:** Watch solutions generate live word-by-word.
* 🛠️ **Automated Bug Diagnosis:** Fixes missing imports, type mismatches, logic errors, and variable scoping bugs.
* 📖 **Clear Explanations:** Explains *why* the code failed and *how* the fix resolves it.
* 🔑 **Configurable API Key:** Custom Gemini API key input directly via the sidebar.
